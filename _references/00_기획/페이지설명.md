# 인트로 페이지 (IntroPage)

> 미진이네 파스타 · 페이지 명세서
> 라우트: `/` · 컴포넌트: `IntroPage`

---

## 1. 페이지 목적

게임 시작 전, 플레이어에게 **"미진이는 왜 파스타 가게를 차리게 되었는가"** 를 전달하는 스토리 인트로 페이지다.

- 남편의 실직 → 미진이의 고민 → "파스타 가게를 차리자!" 라는 결심까지의 흐름을 두 개의 영상으로 자동 재생한다.
- 별도의 건너뛰기·진행 표시 UI는 없다. 인트로는 플레이어 조작 없이 스스로 흘러간다.
- 영상이 모두 끝나면 같은 화면 위에 **"게임 시작" / "게임 방법" 버튼이 나타나** 메인 메뉴 역할까지 이 페이지가 담당한다.

---

## 2. 전체 플로우

```
페이지 진입
   │  (background.mp3 반복 재생 시작 — 이후 모든 단계에서 계속 유지)
   ▼
① intro_gomin.mp4 자동 재생 (실직 & 고민 장면)
   │  ended
   ▼
② intro_aha.mp4 이어서 자동 재생 (아하! 장면)
   │  ended
   ▼
③ 배경: 파스타만들기게임_인트로_아하!.png
   그 위에 [게임 시작] [게임 방법] 버튼 노출
   │
   ├─ [게임 시작] 클릭 ──▶ 본게임 (페이지1 · 면 고르기)
   └─ [게임 방법] 클릭 ──▶ 게임 방법 패널(모달) 열림 → 닫으면 ③으로 복귀
```

- 건너뛰기 버튼, 진행 인디케이터, 컷 수동 넘기기 등은 **없다**.
- 영상 ①→② 전환과 ②→③ 전환은 각각 `ended` 이벤트로 처리한다.
- ②에서 ③으로 넘어갈 때 화면이 튀지 않도록, 영상 마지막 프레임과 동일한 구도의 `파스타만들기게임_인트로_아하!.png` 위에 버튼만 페이드 인한다.

---

## 3. 화면 구성

### ①·② 영상 재생 중

전체 화면(풀블리드)에 영상만 표시한다. UI 없음.

```
┌──────────────────────────────────────────────┐
│                                              │
│                                              │
│           [ 인트로 영상 재생 중 ]               │
│                                              │
│                                              │
└──────────────────────────────────────────────┘
```

### ③ 영상 종료 후 (메뉴 노출)

```
┌──────────────────────────────────────────────┐
│                                              │
│   [ 배경: 파스타만들기게임_인트로_아하!.png ]     │
│                                              │
│              ┌──────────────┐                │
│              │   게임 시작    │                │
│              └──────────────┘                │
│              ┌──────────────┐                │
│              │   게임 방법    │                │
│              └──────────────┘                │
│                                              │
└──────────────────────────────────────────────┘
```

| 영역           | 내용                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 배경           | `파스타만들기게임_인트로_아하!.png` (화면 전체, `object-fit: cover`) |
| 게임 시작 버튼 | 클릭 시 본게임(면 고르기)으로 이동                                   |
| 게임 방법 버튼 | 클릭 시 게임 방법 패널(모달) 오버레이 표시                           |

---

## 4. 사운드

- **BGM**: `background.mp3` — 페이지 진입 시점부터 재생을 시작하고, 영상 ①·② 재생 중과 메뉴 화면 ③까지 **모든 플로우에서 끊김 없이 반복(loop) 재생**한다.
- 인트로 영상 자체의 오디오 트랙은 사용하지 않는다(영상은 muted). BGM 하나로 전체 분위기를 유지한다.
- 브라우저 자동재생 정책상 첫 사용자 입력 전에는 BGM이 막힐 수 있다. → 재생 실패 시 조용히 무시하고, 첫 클릭/탭 시점에 재생을 재시도한다. (영상은 muted 상태이므로 자동 재생에 문제 없음)

---

## 5. 상태

```ts
type IntroStep = "gomin" | "aha" | "menu";

type IntroState = {
  step: IntroStep; // 현재 단계
  isMethodOpen: boolean; // 게임 방법 패널 열림 여부 (step === 'menu'일 때만 유효)
};
```

- `gomin` → `aha` → `menu` 순서로만 진행하며 되돌아가지 않는다.
- 단계 전환은 오직 영상의 `ended` 이벤트로만 일어난다. (타이머 불필요)

---

## 6. 전환

```
IntroPage(menu 단계)
   ├─ [게임 시작] ──▶ GamePage (페이지1 · 면 고르기)
   └─ [게임 방법] ──▶ 게임 방법 모달 (IntroPage 내 오버레이, 라우트 이동 없음)
```

- BGM은 본게임 진입 시 어떻게 할지(계속/교체/정지) 본게임 명세에서 별도로 정한다.

---

## 7. 에셋

| 종류   | 파일                                | 용도                    |
| ------ | ----------------------------------- | ----------------------- |
| 영상   | `src/assets/videos/intro_gomin.mp4` | ① 실직 & 고민 장면      |
| 영상   | `src/assets/videos/intro_aha.mp4`   | ② 아하! 장면            |
| 이미지 | `파스타만들기게임_인트로_아하!.png` | ③ 메뉴 배경             |
| 오디오 | `background.mp3`                    | BGM (전 구간 반복 재생) |

**프리로드**: ① 재생 중에 ② 영상과 ③ 배경 이미지를 미리 불러와 전환 시 공백이 없게 한다.

---

## 8. 예외 처리

- **영상 로드/재생 실패** → 해당 영상 단계를 건너뛰고 다음 단계로 진행한다. (① 실패 시 ②로, ② 실패 시 ③으로) 플레이어에게 에러를 노출하지 않는다.
- **BGM 재생 실패** → 무음으로 진행하고, 첫 사용자 입력 시 재생을 재시도한다.
- **탭 백그라운드 전환** → 영상과 BGM을 일시정지하고, 돌아오면 이어서 재생한다.
- **페이지 이탈** → 영상·오디오 리소스를 모두 정리한다.

---

## 9. 완료 조건 (Acceptance Criteria)

- [ ] 페이지 진입 시 `intro_gomin.mp4`가 자동 재생되고, 끝나면 `intro_aha.mp4`가 이어서 자동 재생된다.
- [ ] 두 영상 사이 전환에 검은 화면/공백 프레임이 보이지 않는다.
- [ ] `intro_aha.mp4` 종료 후 `파스타만들기게임_인트로_아하!.png` 배경 위에 "게임 시작"·"게임 방법" 버튼이 나타난다.
- [ ] 인트로 어느 단계에도 건너뛰기·진행 표시 UI가 없다.
- [ ] `background.mp3`가 진입부터 메뉴 화면까지 끊김 없이 반복 재생된다.
- [ ] "게임 시작" 클릭 시 본게임으로, "게임 방법" 클릭 시 게임 방법 패널이 열린다.
- [ ] 영상 재생에 실패해도 플로우가 멈추지 않고 다음 단계로 진행된다.
- [ ] 페이지를 벗어날 때 영상·오디오 리소스가 모두 정리된다.
